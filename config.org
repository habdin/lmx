* Purpose

Organized init.el emacs configuration. The contents will be tangled to init.el.

** Load distribution packages
All distribution packages are loaded. The `require' command is used since the
load path is already defined in early-init.el. You won't be able to load any
custom functions in distrib-helpers. Emacs will not start correctly.

#+BEGIN_SRC emacs-lisp :tangle yes

  (require 'distrib-helpers)
  (require 'distrib-packagers)
  (require 'distrib-ui)
  (require 'distrib)
  
#+END_SRC
